Jarvis privacy policy

Last updated October 3, 2026.

Jarvis is a private household assistant run by its owner on his own computer. Its only users are the owner and one family member. This policy describes what it does with Google account data.

What Jarvis accesses

With the owner's consent, Jarvis accesses the owner's own Google account: it reads Gmail messages, creates drafts and sends a draft only after the owner has read and approved it, and reads, adds, changes and removes Google Calendar events.

How the data is used

The data is used only to answer questions and carry out requests that the owner or the family member sends to Jarvis by text message. It is not used for advertising, is not sold, and is not used to train any general-purpose model.

Where the data goes

Jarvis runs on the owner's computer. To write a reply, the relevant message or event text is sent to Anthropic's Claude, the AI model that Jarvis runs on, under the owner's own account. It is shared with no one else. Mail on sensitive subjects, such as health, credentials and financial documents, is withheld by code before any of it reaches the model.

What is kept

Jarvis keeps a log of the text messages it received and the replies it sent, on the owner's computer only. It does not keep a copy of the mailbox or the calendar. The Google sign-in is stored in the computer's encrypted keychain.

Google API Services User Data Policy

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Jarvis's access at any time from the Google Account permissions page, which ends all access immediately.
